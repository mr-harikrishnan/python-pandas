# Distribution Plots (Status 1002, Error 503)

## Folder Purpose
This folder contains 11 PNG distribution plots comparing pass vs fail measurements for status code 1002 and error code 503.

## What this folder does
- Visualizes pass vs fail bell curves for continuous sensor columns under error 503.
- Enables visual inspection of parameter shifts, variance changes, and zero-value clusters.

## Main files/components and their purpose
- 11 PNG plot files representing key parameters:
  - `EB1_ANLIEF_MG.png`, `EB1_AUSLIEF_MG.png`: EB1 unbalance delivery and delivery measurements.
  - `EB2_ANLIEF_MG.png`, `EB2_AUSLIEF_MG.png`: EB2 unbalance delivery and delivery measurements.
  - `MD1_ANLIEF_MG.png`, `MD1_AUSLIEF_MG.png`: MD1 unbalance delivery and delivery measurements.
  - `MD2_ANLIEF_MG.png`, `MD2_AUSLIEF_MG.png`: MD2 unbalance delivery and delivery measurements.
  - `MD3_ANLIEF_MG.png`, `MD3_AUSLIEF_MG.png`: MD3 unbalance delivery and delivery measurements.
  - `OEL_DRUCK.png`: Oil pressure distribution.
  - `OEL_TEMPERATUR.png`: Oil temperature distribution.
  - `PF_TORQUE.png`: Profile torque distribution.
  - `SPANN_DRUCK.png`: Clamping pressure distribution.

## How it works
- Generated by `pass_fail_distribution_continuous_data_float_value_columns/main.py`.

## Important notes or dependencies
- Green curves represent pass data, red curves represent fail data.
