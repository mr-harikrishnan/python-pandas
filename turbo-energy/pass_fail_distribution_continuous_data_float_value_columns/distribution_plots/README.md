# Distribution Plots Root

## Folder Purpose
This folder serves as the central directory storing all generated normal distribution comparison plots for continuous sensor columns.

## What this folder does
- Organizes generated PNG distribution plots into subdirectories categorized by status code and error code.

## Main files/components and their purpose
- `status_code-1002-err_code-503-merged_CEMB_141E_141C_141A_141B_and_141D/`: Plots for status 1002 error 503.
- `status_code-1002-err_code-513-merged_CEMB_141E_141C_141A_141B_and_141D/`: Plots for status 1002 error 513.
- `status_code-1002-err_code-555-merged_CEMB_141E_141C_141A_141B_and_141D/`: Plots for status 1002 error 555.
- `status_code-1011-err_code-16-merged_CEMB_141E_141C_141A_141B_and_141D/`: Plots for status 1011 error 16.

## How it works
- Created and populated automatically by running `main.py` in the parent directory.

## Important notes or dependencies
- Visual plots assist engineers in identifying which sensor parameters deviate during specific failure modes.
