# Distribution Plots (Status 1011, Error 16)

## Folder Purpose
This folder contains 11 PNG distribution plots comparing pass vs fail measurements for status code 1011 and error code 16.

## What this folder does
- Displays comparative bell curves for continuous float sensor metrics associated with failure code 16.

- 11 PNG plot files covering sensor variables including:

  - `EB2_ANLIEF_MG.png`, `EB2_AUSLIEF_MG.png`
  - `MD1_ANLIEF_MG.png`, `MD1_AUSLIEF_MG.png`
  - `MD2_ANLIEF_MG.png`, `MD2_AUSLIEF_MG.png`
