# Merged CSVs (Merging Pipeline)

## Folder Purpose
This folder stores final merged multi-machine datasets partitioned by status and error codes.

## What this folder does
- Combines data from all CEMB balancing machines (141A through 141E) with core correlation data into unified CSVs.
- Partitions datasets into pass records and specific error code records.

## Main files/components and their purpose
- 10 merged CSV files categorized by status code and error code:
  - Pass dataset: status 1001, error 0.
  - Fail datasets: status 1002 (errors 503, 513, 555), status 1011 (error 16).
  - Merged datasets combining all status 1002 failure codes.

## How it works
- Generated by `turbo-energy-merging/main.py`.

## Important notes or dependencies
- These files serve as the primary inputs for bell curve comparisons, zero-value detection, and statistical distribution modeling across the project.
