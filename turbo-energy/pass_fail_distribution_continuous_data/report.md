The value `909090` appears simultaneously across eight related CW parameters:

- `Min_Val_Load_CW_W1`
- `Max_Val_Load_CW_W1`
- `Min_Val_Distance_CW_W1`
- `Max_Val_Distance_CW_W1`
- `Min_Val_Load_CW_W2`
- `Max_Val_Load_CW_W2`
- `Min_Val_Distance_CW_W2`
- `Max_Val_Distance_CW_W2`

The same abnormal value is present in both Pass and Fail data.

Therefore, `909090` should not be directly interpreted as a Fail-specific value.

It should first be investigated as a possible invalid/sentinel/data-quality value.
